Abuse protection

AI requests are checked by Cloudflare Turnstile. Kelly does not use an application access password. This is bot protection, not private-user authentication.

Storage

Reminders and chat history are stored in this browser on this device. Cross-device sync is not enabled yet.

Notifications & background reminders

Server push is not enabled in this first release. Use Add to Apple Calendar for alerts managed by iOS Calendar.

Add Kelly to your Home Screen
